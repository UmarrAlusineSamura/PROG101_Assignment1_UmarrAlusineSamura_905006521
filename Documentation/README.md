# FLOODCONNECT SL – PROJECT DOCUMENTATION

## Overview

This folder contains documentation relating to the design and development of the Community Flood Reporting and Response Management System for Sierra Leone (FloodConnect SL).

## Project Contents

The project documentation covers:

1. Project background and problem description.
2. Proposed system and objectives.
3. Computational thinking concepts.
4. System algorithms and pseudocode.
5. Flowchart designs.
6. Functional modules and expected outputs.
7. References and supporting resources.

## System Modules

* Main System Navigation
* Administrator Login and Report Verification
* Resident Flood Reporting
* Response Team Task Management

## Purpose

The documentation explains the logical design, structure and intended operation of FloodConnect SL.

**Project:** PROG101 Assignment 1
